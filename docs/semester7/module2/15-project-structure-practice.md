# 15. (П8) Структура проєкту: відокремлення інтерфейсу від логіки

## Мета роботи

- **Освітня (навчальна):** навчитися структурувати проєкт PySide6 у пакети (`models`, `services`, `ui`), відокремлювати логіку застосунку від інтерфейсу та тестувати логіку без запуску графічного інтерфейсу.
- **Дослідна (розвиваюча):** розвинути вміння аналізувати залежності між модулями й знаходити місця, де інтерфейс «знає» забагато про дані.
- **Виховна (патріотична):** сформувати культуру впорядкованої організації проєкту для командної роботи над великими продуктами.

!!! danger "Персоналізація обовʼязкова"
    Ви рефакторите **ваш** застосунок `expense_tracker` з робіт П4–П7; поведінка для користувача не змінюється.

## Підготовка

Зробіть коміт поточного стану `expense_tracker` у Git перед рефакторингом. Встановіть `pytest`.

## Хід роботи

### Завдання 1. Нова структура

Розкладіть код за пакетами:

```text
expense_tracker/
  main.py                 # лише створення QApplication і вікна
  expense_tracker/
    __init__.py
    models.py             # клас Expense (дані без Qt)
    storage.py            # читання і запис CSV
    services.py           # підрахунки: суми, фільтри, бюджет
    ui/
      __init__.py
      main_window.py
      expense_dialog.py
  tests/
    test_services.py
```

**Очікуваний результат:** модулі `models.py`, `storage.py` і `services.py` не імпортують нічого з `PySide6`; застосунок запускається командою `python main.py` і працює як раніше.

### Завдання 2. Модель даних

Файл `models.py`:

```python
from dataclasses import dataclass
from datetime import date


@dataclass
class Expense:
    spent_on: date
    category: str
    amount: float
    comment: str = ""

    def __post_init__(self):
        if self.amount <= 0:
            raise ValueError("amount must be positive")


print(Expense(date(2026, 9, 21), "food", 85.5, "lunch"))
```

Видаліть рядок з `print` після перевірки і перенесіть у `storage.py` функції `load(path)` та `save(path, expenses)`.

**Очікуваний результат:** вікно працює з обʼєктами `Expense`, а не з рядками CSV.

### Завдання 3. Тести логіки

Файл `tests/test_services.py`. Напишіть тести для функцій `total`, `by_category`, `filter_by_category` і `budget_left` на ваших реальних даних.

**Очікуваний результат:** `pytest -v` проходить без запуску жодного вікна і без встановленого дисплея.

### Завдання 4. Перевірка залежностей

Виконайте `grep -rn "PySide6" expense_tracker/` і переконайтеся, що імпорти Qt є лише в пакеті `ui`. Намалюйте схему залежностей між модулями (mermaid).

**Очікуваний результат:** у схемі стрілки йдуть лише від `ui` до логіки, але не навпаки.
