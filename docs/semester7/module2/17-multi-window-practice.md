# 17. (П9) Багатовіконний застосунок

## Мета роботи

- **Освітня (навчальна):** навчитися створювати застосунок з кількома вікнами, відкривати модальні та немодальні вікна, передавати дані між вікнами через параметри конструктора й сигнали.
- **Дослідна (розвиваюча):** розвинути вміння досліджувати життєвий цикл вікон і знаходити причини їх «зникнення» або дублювання.
- **Виховна (патріотична):** сформувати прагнення створювати цілісні програмні продукти, у яких частини узгоджено працюють разом.

!!! danger "Персоналізація обовʼязкова"
    Вікно «About» містить **ваші** дані як автора, а налаштування — ваш бюджет і валюту.

## Підготовка

Скористайтеся структурою `expense_tracker` з роботи П8. Нові вікна розміщуйте в пакеті `ui`.

## Хід роботи

### Завдання 1. Вікно «About»

Створіть модальне вікно `AboutDialog(QDialog)` з назвою застосунку, версією, вашим імʼям, групою та роком. Відкривається з меню `Help → About`.

**Очікуваний результат:** поки вікно відкрите, головне вікно недоступне.

### Завдання 2. Вікно налаштувань

Створіть немодальне вікно `SettingsWindow(QWidget)` з полями: місячний бюджет, валюта (`UAH`, `USD`, `EUR`), папка з даними. Кнопка `Apply` надсилає сигнал `settings_changed(dict)`, на який підписане головне вікно.

```python
from PySide6.QtCore import Signal
from PySide6.QtWidgets import QDoubleSpinBox, QFormLayout, QPushButton, QWidget


class SettingsWindow(QWidget):
    settings_changed = Signal(dict)

    def __init__(self, budget):
        super().__init__()
        self.setWindowTitle("Settings")
        layout = QFormLayout(self)
        self.budget = QDoubleSpinBox()
        self.budget.setRange(0, 1_000_000)
        self.budget.setValue(budget)
        layout.addRow("Monthly budget", self.budget)
        apply_button = QPushButton("Apply")
        apply_button.clicked.connect(self.apply)
        layout.addRow(apply_button)

    def apply(self):
        self.settings_changed.emit({"budget": self.budget.value()})
```

**Очікуваний результат:** після `Apply` головне вікно оновлює бюджет та індикатор з роботи П7, а вікно налаштувань залишається відкритим.

### Завдання 3. Одне вікно — один екземпляр

Повторне вибрання `Settings` не створює нове вікно, а активує вже відкрите (`raise_()`, `activateWindow()`). Поясніть, чому вікно, створене локальною змінною в методі, одразу зникає.

**Очікуваний результат:** скільки б разів не обрати пункт меню, відкрито лише одне вікно налаштувань.

### Завдання 4. Вікно перегляду витрати

Подвійний клік на витраті відкриває немодальне вікно з її деталями та кнопкою `Edit`. Після редагування зміни відображаються в головному вікні.

**Очікуваний результат:** можна відкрити кілька вікон перегляду різних витрат одночасно; закриття головного вікна закриває всі інші.
