# 21. (П11) Фонові задачі без блокування інтерфейсу

## Мета роботи

- **Освітня (навчальна):** навчитися виконувати тривалі операції у фоновому потоці (`QThreadPool` і `QRunnable` або `QThread`), передавати проміжні результати й прогрес в інтерфейс через сигнали та скасовувати фонову задачу.
- **Дослідна (розвиваюча):** розвинути розуміння причин «зависання» інтерфейсу і вміння знаходити операції, які потрібно винести з головного потоку.
- **Виховна (патріотична):** сформувати увагу до зручності користувача під час тривалих операцій: людина має бачити прогрес і мати змогу скасувати дію.

!!! danger "Персоналізація обовʼязкова"
    Фонові задачі сканують **ваш** домашній каталог і завантажують курси НБУ за **ваш** місяць народження (як у роботі П17 6 семестру).

## Підготовка

## Хід роботи

### Завдання 1. Заморожений інтерфейс

Створіть кнопку `Scan`, що в обробнику рахує файли вашого домашнього каталогу (`Path.home().rglob("*")`). Під час сканування спробуйте перемістити вікно.

**Очікуваний результат:** під час сканування вікно не реагує; у звіті пояснено, чому.

### Завдання 2. Робітник у пулі потоків

Перенесіть сканування в клас-робітник:

```python
from pathlib import Path

from PySide6.QtCore import QObject, QRunnable, Signal


class ScanSignals(QObject):
    progress = Signal(int)       # кількість переглянутих файлів
    finished = Signal(int, int)  # кількість файлів, загальний розмір


class ScanWorker(QRunnable):
    def __init__(self, folder, pattern):
        super().__init__()
        self.folder = Path(folder)
        self.pattern = pattern
        self.signals = ScanSignals()
        self.cancelled = False

    def run(self):
        count = size = 0
        for path in self.folder.rglob(self.pattern):
            if self.cancelled:
                break
            if path.is_file():
                count += 1
                size += path.stat().st_size
                if count % 100 == 0:
                    self.signals.progress.emit(count)
        self.signals.finished.emit(count, size)
```

Запустіть робітника через `QThreadPool.globalInstance().start(worker)` і показуйте прогрес у рядку стану.

**Очікуваний результат:** під час сканування вікно реагує, а рядок стану оновлюється кожні 100 файлів.

### Завдання 3. Скасування

Додайте кнопку `Cancel`, що встановлює `worker.cancelled = True`. Під час виконання кнопка `Scan` неактивна, після завершення або скасування — знову активна.

**Очікуваний результат:** після натискання `Cancel` сканування зупиняється, а результат показує частковий підрахунок.

### Завдання 4. Завантаження курсів у фоні

Створіть робітника, що завантажує курси USD за ваш місяць народження, і показуйте прогрес у `QProgressBar` (від 0 до кількості днів). Помилки мережі передавайте сигналом `failed(str)` і показуйте в `QMessageBox`.

**Очікуваний результат:** інтерфейс не блокується під час завантаження, а вимкнення інтернету дає повідомлення, а не падіння застосунку.

### Завдання 5. Правило головного потоку

Спробуйте змінити віджет (`label.setText`) безпосередньо з методу `run()` робітника і зафіксуйте поведінку. Поверніть правильний варіант через сигнал.

**Очікуваний результат:** у звіті пояснено, чому змінювати віджети можна лише з головного потоку.
