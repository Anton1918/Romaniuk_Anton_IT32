## Хід роботи

### Завдання 1. Дашборд 2×2

Файл `task1.py`:

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(20070307)  # дата вашого народження
fig, axes = plt.subplots(2, 2, figsize=(12, 8), layout="constrained")
fig.suptitle("Expenses dashboard - Ivan Petrenko, PZ-11")
axes[0, 0].plot(np.cumsum(rng.uniform(0, 200, 30)))
axes[0, 0].set_title("cumulative")
axes[0, 1].hist(rng.normal(150, 40, 300), bins=20)
axes[0, 1].set_title("distribution")
axes[1, 0].scatter(rng.uniform(1, 30, 50), rng.uniform(0, 300, 50))
axes[1, 0].set_title("by day")
axes[1, 1].bar(["food", "transport", "fun"], [640, 210, 395])
axes[1, 1].set_title("by category")
fig.savefig("dashboard.png", dpi=300)
```

Замініть згенеровані дані на ваші реальні витрати.
