### Завдання 3. Анотації та акценти

```python
import matplotlib.pyplot as plt

years = [2019, 2020, 2021, 2022, 2023, 2024]
values = [120, 135, 150, 95, 110, 140]
fig, ax = plt.subplots()
ax.plot(years, values, color="gray", marker="o")
ax.annotate("drop in 2022", xy=(2022, 95), xytext=(2019.5, 100),
            arrowprops={"arrowstyle": "->"})
ax.grid(axis="y", alpha=0.3)
ax.spines[["top", "right"]].set_visible(False)
fig.savefig("annotated.png", dpi=150)
```

Додайте до вашого головного графіка анотацію найважливішої точки, виділіть її кольором, приберіть зайві рамки, додайте ледь помітну сітку та підпис джерела даних під графіком (`fig.text`).

**Очікуваний результат:** графік містить анотацію, підпис джерела і не містить зайвих елементів.
