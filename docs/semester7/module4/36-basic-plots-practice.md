## Хід роботи

### Завдання 1. Графік функції

Файл `task1.py`:

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(-10, 10, 201)
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, x ** 2, label="y = x^2")
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_title("Ivan Petrenko, PZ-11")
ax.legend()
Path("plots").mkdir(exist_ok=True)
fig.savefig("plots/task1.png", dpi=150)
```

Додайте на ті самі осі `y = x³ / 10` і `y = 10·sin(x)` з різними кольорами та стилями ліній.

**Очікуваний результат:** файл `plots/task1.png` з трьома лініями, легендою та вашим імʼям у заголовку.
