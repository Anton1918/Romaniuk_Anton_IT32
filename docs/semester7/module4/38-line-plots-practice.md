### Завдання 3. Дві осі Y

```python
import matplotlib.pyplot as plt
import numpy as np

days = np.arange(1, 31)
spent = np.cumsum(np.full(30, 40.0))
rate = 41 + np.sin(days / 5) / 2
fig, ax_spent = plt.subplots()
ax_rate = ax_spent.twinx()
ax_spent.plot(days, spent, color="tab:blue", label="spent, UAH")
ax_rate.plot(days, rate, color="tab:red", linestyle="--", label="USD rate")
ax_spent.set_ylabel("spent, UAH", color="tab:blue")
ax_rate.set_ylabel("USD rate", color="tab:red")
fig.legend(loc="upper left")
fig.savefig("twin_axes.png", dpi=150)
```

**Очікуваний результат:** кольори підписів осей збігаються з кольорами ліній, легенда містить обидві лінії.
