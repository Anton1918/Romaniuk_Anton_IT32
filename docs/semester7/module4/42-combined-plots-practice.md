### Завдання 2. Згрупована та накопичена діаграми

За зведеною таблицею «тижні × категорії» побудуйте поруч дві діаграми: згруповану (стовпці категорій поруч для кожного тижня) і з накопиченням (`bottom=`).

```python
import matplotlib.pyplot as plt
import numpy as np

weeks = ["w1", "w2", "w3", "w4"]
food = np.array([420, 380, 450, 300])
transport = np.array([120, 90, 150, 80])
fig, ax = plt.subplots()
ax.bar(weeks, food, label="food")
ax.bar(weeks, transport, bottom=food, label="transport")
ax.set_ylabel("UAH")
ax.legend()
fig.savefig("stacked.png", dpi=150)
```

**Очікуваний результат:** у звіті пояснено, на яке запитання краще відповідає кожна з двох діаграм.
