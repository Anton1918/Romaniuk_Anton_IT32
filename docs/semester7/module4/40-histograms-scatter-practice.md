### Завдання 3. Діаграма розсіювання з трендом

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(20070307)  # дата вашого народження
x = rng.uniform(0, 30, 100)
y = 2.5 * x + rng.normal(0, 10, 100)
slope, intercept = np.polyfit(x, y, 1)
fig, ax = plt.subplots()
points = ax.scatter(x, y, c=y, s=20 + x * 3, cmap="viridis", alpha=0.7)
ax.plot(np.sort(x), slope * np.sort(x) + intercept, color="red", label=f"y = {slope:.2f}x + {intercept:.2f}")
fig.colorbar(points, label="y")
ax.legend()
fig.savefig("scatter.png", dpi=150)
```

Побудуйте діаграму розсіювання ваших витрат: вісь X — день місяця, вісь Y — сума, колір — категорія (окремий `scatter` для кожної категорії з легендою).

**Очікуваний результат:** на графіку видно, які категорії переважають у великих витратах.
