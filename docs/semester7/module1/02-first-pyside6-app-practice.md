# 2. (П1) Перший застосунок PySide6

## Мета роботи

- **Освітня (навчальна):** навчитися встановлювати PySide6 у віртуальне середовище, створювати обʼєкт `QApplication`, головне вікно та віджети, запускати цикл обробки подій і обробляти натискання кнопки.
- **Дослідна (розвиваюча):** розвинути вміння самостійно знаходити потрібні класи й методи в документації Qt for Python і перевіряти їхню роботу на власних прикладах.
- **Виховна (патріотична):** сформувати увагу до зручності інтерфейсу для користувача — якість цифрових продуктів визначає довіру до них.

!!! danger "Персоналізація обовʼязкова"
    Заголовок вікна містить ваше імʼя та групу, а застосунок показує **ваші** дані.

## Підготовка

1. Створіть каталог `lab01_pyside` з віртуальним середовищем і встановіть `PySide6`.
2. Перевірте встановлення: `python -c "import PySide6; print(PySide6.__version__)"`.
3. У VS Code оберіть інтерпретатор з `.venv` (`Python: Select Interpreter`).

!!! warning "Вимоги до інтерфейсу"
    Увесь текст у вікнах — латиницею (вимога курсу до рядків у коді). Кирилиця допускається лише в коментарях.

## Хід роботи

### Завдання 1. Порожнє вікно

Файл `task1.py`:

```python
import sys

from PySide6.QtWidgets import QApplication, QWidget

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Ivan Petrenko, PZ-11")
window.resize(400, 200)
window.show()
sys.exit(app.exec())
```

**Очікуваний результат:** відкривається вікно з вашим імʼям у заголовку; програма завершується після закриття вікна, а код завершення дорівнює `0`.

### Завдання 2. Віджети й компоновка

Файл `task2.py`. Додайте у вікно напис `QLabel` з вашим привітанням, поле `QLineEdit` і кнопку `QPushButton("Greet")`, розміщені вертикально (`QVBoxLayout`). Натискання кнопки змінює текст напису на `Hello, <текст з поля>!`.

**Очікуваний результат:** після введення імені й натискання кнопки напис змінюється; натискання клавіші Enter у полі дає той самий результат (сигнал `returnPressed`).

### Завдання 3. Калькулятор

Файл `task3.py`. Створіть калькулятор з двома полями для чисел, чотирма кнопками операцій (`+`, `-`, `*`, `/`) і написом для результату. Ділення на нуль і нечислове введення показують повідомлення про помилку в написі, програма не падає.

**Очікуваний результат:** калькулятор правильно рахує ваш приклад: сума днів і місяців вашого народження, поділена на номер у списку групи.

### Завдання 4. Клас вікна

Перепишіть завдання 3 як клас `CalculatorWindow(QWidget)`: віджети створюються в `__init__`, обробники — методи класу.

**Очікуваний результат:** поведінка не змінилася, а код у кінці файлу містить лише створення застосунку, вікна й запуск циклу.
