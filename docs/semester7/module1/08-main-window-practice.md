# 8. (П4) Каркас застосунку на основі QMainWindow

## Мета роботи

- **Освітня (навчальна):** навчитися створювати головне вікно `QMainWindow` з центральним віджетом, рядком стану та док-панеллю, організовувати код вікна в класі.
- **Дослідна (розвиваюча):** розвинути вміння проєктувати структуру головного вікна відповідно до сценаріїв роботи користувача.
- **Виховна (патріотична):** сформувати прагнення створювати цілісні та зручні інструменти для щоденної роботи.

!!! danger "Персоналізація обовʼязкова"
    Головне вікно — каркас **вашого** застосунку витрат «Expense Tracker — Ivan Petrenko», який ви розвиватимете до кінця модуля.

## Підготовка

Створіть каталог `expense_tracker` — у ньому ви працюватимете в роботах П4–П7. Скопіюйте `data/expenses.csv`.

## Хід роботи

### Завдання 1. Головне вікно

Файл `main.py`:

```python
import sys

from PySide6.QtWidgets import QApplication, QMainWindow, QTextEdit


class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Expense Tracker - Ivan Petrenko")
        self.resize(800, 500)
        self.editor = QTextEdit()
        self.setCentralWidget(self.editor)
        self.statusBar().showMessage("ready")


if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

**Очікуваний результат:** вікно з текстовим полем у центрі та написом `ready` у рядку стану.

### Завдання 2. Відображення витрат

Замініть `QTextEdit` на `QListWidget`, що під час запуску завантажує ваші витрати з `data/expenses.csv` у форматі `21.09.2026  food  85.50  lunch`. У рядку стану виведіть кількість витрат і загальну суму.

**Очікуваний результат:** список містить усі ваші витрати, а сума в рядку стану збігається з результатами 5 семестру.

### Завдання 3. Док-панель фільтра

Додайте док-панель (`QDockWidget`) ліворуч із `QComboBox` категорій (перший пункт — `all`). Вибір категорії фільтрує список і оновлює рядок стану.

**Очікуваний результат:** док-панель можна відкріпити й перемістити, а фільтр працює для кожної вашої категорії.

### Завдання 4. Збереження розміру вікна

Під час закриття вікна (`closeEvent`) виведіть у консоль поточний розмір і положення вікна — у роботі П12 ви збережете їх у налаштуваннях.

**Очікуваний результат:** у консолі після закриття видно розмір і положення, що відповідають останньому стану вікна.
