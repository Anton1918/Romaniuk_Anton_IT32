## Мета роботи

- **Освітня (навчальна):** навчитися створювати форму з віджетами `QLineEdit`, `QSpinBox`, `QComboBox`, `QRadioButton`, `QCheckBox`, `QDateEdit`, зчитувати їхні значення та перевіряти введені дані.
- **Дослідна (розвиваюча):** розвинути вміння обирати віджет відповідно до типу даних і обмежувати введення ще до перевірки.
- **Виховна (патріотична):** сформувати повагу до користувача через продуману форму, що не дозволяє помилитися, — як у якісних державних електронних сервісах.

!!! danger "Персоналізація обовʼязкова"
    Форма призначена для введення **ваших** витрат: категорії у списку — ваші категорії з 5–6 семестрів.

## Підготовка

Створіть каталог `lab02_form` з віртуальним середовищем і PySide6.

## Хід роботи

### Завдання 1. Форма нової витрати

Файл `task1.py`. Створіть вікно з формою (`QFormLayout`):

| Поле | Віджет | Обмеження |
|---|---|---|
| Date | `QDateEdit` | календар, не пізніше сьогодні |
| Category | `QComboBox` | ваші категорії |
| Amount | `QDoubleSpinBox` | від 0.01 до 100000, два знаки |
| Payment | `QRadioButton` ×2 | `cash` / `card` |
| Comment | `QLineEdit` | до 100 символів |
| Recurring | `QCheckBox` | регулярна витрата |

```python
import sys

from PySide6.QtCore import QDate
from PySide6.QtWidgets import (
    QApplication, QComboBox, QDateEdit, QDoubleSpinBox, QFormLayout, QWidget,
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("New expense - Ivan Petrenko")
form = QFormLayout(window)

date_edit = QDateEdit(QDate.currentDate())
date_edit.setCalendarPopup(True)
date_edit.setMaximumDate(QDate.currentDate())
form.addRow("Date", date_edit)

category = QComboBox()
category.addItems(["food", "transport", "fun"])
form.addRow("Category", category)

amount = QDoubleSpinBox()
amount.setRange(0.01, 100000)
amount.setDecimals(2)
form.addRow("Amount", amount)

window.show()
sys.exit(app.exec())
```

Додайте решту полів і кнопку `Save`.

**Очікуваний результат:** обмеження працюють на рівні віджетів: неможливо обрати майбутню дату або ввести від’ємну суму.

### Завдання 2. Зчитування та перевірка

Натискання `Save` збирає значення полів у словник і виводить його в консоль. Якщо не обрано спосіб оплати або коментар містить лише пробіли — показати повідомлення під формою червоним текстом і не зберігати.

**Очікуваний результат:** коректна витрата виводиться словником, некоректна — не зберігається, а повідомлення вказує на конкретне поле.

### Завдання 3. Збереження у файл

Додавайте кожну збережену витрату в ваш `data/expenses.csv` у форматі `date;category;amount;comment`. Після збереження форма очищується, курсор переходить у поле суми.

**Очікуваний результат:** нові рядки зʼявляються наприкінці файлу, а програми робіт 5 семестру читають їх без помилок.

Налаштуйте порядок переходу між полями клавішею Tab (`setTabOrder`) і зробіть кнопку `Save` кнопкою за замовчуванням (Enter).
