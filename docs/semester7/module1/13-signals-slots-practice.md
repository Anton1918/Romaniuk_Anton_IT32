# 13. (П7) Сигнали та слоти на практиці

## Мета роботи

- **Освітня (навчальна):** навчитися оголошувати власні сигнали (`Signal`), передавати через них дані, під’єднувати та від’єднувати слоти й обробляти події віджетів.
- **Дослідна (розвиваюча):** розвинути вміння зменшувати залежність між компонентами інтерфейсу та перевіряти, що компонент можна використати повторно без змін.
- **Виховна (патріотична):** сформувати культуру модульного та зрозумілого коду, з яким зручно працювати команді.

!!! danger "Персоналізація обовʼязкова"
    Продовжуйте **ваш** застосунок `expense_tracker`; ліміт бюджету — ваш реальний місячний бюджет.

## Підготовка

Скористайтеся проєктом `expense_tracker`. Сигнали оголошуються на рівні класу, що наслідує `QObject` (або будь-який віджет).

## Хід роботи

### Завдання 1. Власний сигнал

Файл `budget.py`. Створіть клас `Budget(QObject)` з власними сигналами:

```python
from PySide6.QtCore import QObject, Signal


class Budget(QObject):
    changed = Signal(float)      # новий залишок
    exceeded = Signal(float)     # на скільки перевищено ліміт

    def __init__(self, limit):
        super().__init__()
        self.limit = limit
        self.spent = 0.0

    def add(self, amount):
        self.spent += amount
        left = self.limit - self.spent
        self.changed.emit(left)
        if left < 0:
            self.exceeded.emit(-left)


budget = Budget(6000)
budget.changed.connect(lambda left: print(f"left: {left:.2f}"))
budget.exceeded.connect(lambda over: print(f"over by {over:.2f}"))
budget.add(5000)
budget.add(1500)
```

**Очікуваний результат:** програма виводить `left: 1000.00`, `left: -500.00` і `over by 500.00`.

### Завдання 2. Індикатор бюджету

Додайте до головного вікна `QProgressBar`, що показує частку витраченого бюджету. Індикатор під’єднується до сигналу `changed` і не знає нічого про список витрат. Під час перевищення ліміту (`exceeded`) рядок стану стає червоним.

**Очікуваний результат:** додавання та видалення витрат одразу змінює індикатор, хоча код списку не викликає методів індикатора напряму.

### Завдання 3. Кілька слотів і від’єднання

Під’єднайте до `exceeded` два слоти: показ повідомлення і запис у журнал `budget.log`. Додайте прапорець `Notify me`, що від’єднує (`disconnect`) і знову під’єднує слот з повідомленням.

**Очікуваний результат:** з вимкненим прапорцем повідомлення не показується, а запис у журнал продовжує працювати.

### Завдання 4. Повторне використання компонента

Створіть віджет `ExpenseInput(QWidget)` (поле суми й кнопка `Add`) із сигналом `expense_entered = Signal(float)`. Розмістіть два такі віджети у вікні (для готівки й картки) і під’єднайте обидва до одного бюджету.

**Очікуваний результат:** обидва віджети працюють з одним бюджетом, а код `ExpenseInput` не містить посилань на `Budget` чи головне вікно.
