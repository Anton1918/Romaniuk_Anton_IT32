- **Дослідна (розвиваюча):** розвинути вміння організовувати команди застосунку за групами й перевіряти, що одна дія однаково працює з усіх місць виклику.
- **Виховна (патріотична):** сформувати культуру послідовного й передбачуваного інтерфейсу, яким зручно користуватися без інструкції.

## Хід роботи

### Завдання 1. Дії та меню

Створіть дії й розмістіть їх у меню:

| Меню | Дія | Клавіші |
|---|---|---|
| File | `Reload`, `Exit` | `F5`, `Ctrl+Q` |
| Edit | `Add expense`, `Delete expense` | `Ctrl+N`, `Del` |
| View | `Show filter panel` (з прапорцем) | `Ctrl+F` |
| Help | `About` | `F1` |

```python
from PySide6.QtGui import QAction, QKeySequence


def create_actions(window):
    exit_action = QAction("Exit", window)
    exit_action.setShortcut(QKeySequence("Ctrl+Q"))
    exit_action.setStatusTip("Close the application")
    exit_action.triggered.connect(window.close)
    file_menu = window.menuBar().addMenu("File")
    file_menu.addAction(exit_action)
    return {"exit": exit_action}
```

**Очікуваний результат:** кожна дія працює з меню й за комбінацією клавіш, а підказка `statusTip` зʼявляється в рядку стану під час наведення.

### Завдання 2. Панель інструментів

Додайте панель інструментів з діями `Reload`, `Add expense`, `Delete expense` з іконками. Дія `Show filter panel` (з `setCheckable(True)`) показує і приховує док-панель з роботи П4 та синхронізується з нею, якщо панель закрили хрестиком.

**Очікуваний результат:** ті самі обʼєкти `QAction` використовуються в меню й на панелі; стан прапорця завжди відповідає видимості панелі.

### Завдання 3. Стан дій

Дія `Delete expense` вимкнена (`setEnabled(False)`), доки в списку не обрано витрату. Після видалення список і рядок стану оновлюються.

**Очікуваний результат:** неможливо викликати видалення без вибору ні з меню, ні з панелі, ні клавішею `Del`.

### Завдання 4. Контекстне меню

Додайте до списку витрат контекстне меню (права кнопка миші) з діями `Delete expense` і `Copy as text` (копіює рядок витрати в буфер обміну).

**Очікуваний результат:** контекстне меню показується лише над елементом списку, а скопійований текст вставляється в будь-який редактор.
