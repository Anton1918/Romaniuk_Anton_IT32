# 12. (П6) Діалоги відкриття файлів і підтвердження дій

## Мета роботи

- **Освітня (навчальна):** навчитися використовувати стандартні діалоги `QFileDialog` і `QMessageBox`, створювати власний діалог на основі `QDialog` та обробляти результат вибору користувача, зокрема скасування.
- **Дослідна (розвиваюча):** розвинути вміння передбачати дії користувача, що можуть призвести до втрати даних, і захищати від них інтерфейс.
- **Виховна (патріотична):** сформувати відповідальне ставлення до даних користувача: жодна дія не повинна знищувати їх без попередження.

!!! danger "Персоналізація обовʼязкова"
    Продовжуйте **ваш** застосунок `expense_tracker` з робіт П4–П5.

## Підготовка

Скористайтеся проєктом `expense_tracker`. Створіть копію `data/expenses.csv` для експериментів.

## Хід роботи

### Завдання 1. Відкриття і збереження файлу

Додайте дії `Open...` (`Ctrl+O`) і `Save as...` (`Ctrl+Shift+S`):

```python
from PySide6.QtWidgets import QFileDialog


def choose_file(parent):
    path, _ = QFileDialog.getOpenFileName(
        parent, "Open expenses", "data", "CSV files (*.csv);;All files (*)"
    )
    return path or None  # порожній рядок означає «Скасувати»
```

Назва відкритого файлу показується в заголовку вікна.

**Очікуваний результат:** можна відкрити будь-який CSV з витратами і зберегти поточний список в інший файл; натискання «Скасувати» нічого не змінює.

### Завдання 2. Підтвердження видалення

Перед видаленням витрати показуйте `QMessageBox.question` з текстом витрати і кнопками `Yes`/`No` (за замовчуванням — `No`).

**Очікуваний результат:** витрата видаляється лише після підтвердження.

### Завдання 3. Незбережені зміни

Ведіть ознаку незбережених змін (`setWindowModified(True)` і символ `[*]` у заголовку). Під час закриття вікна або відкриття іншого файлу з незбереженими змінами показуйте діалог `Save`/`Discard`/`Cancel`.

**Очікуваний результат:** вибір `Cancel` залишає вікно відкритим, `Save` зберігає й закриває, `Discard` закриває без збереження.

### Завдання 4. Власний діалог «Нова витрата»

Перенесіть форму з роботи П2 у клас `ExpenseDialog(QDialog)` з кнопками `QDialogButtonBox` (`Ok`, `Cancel`). Дія `Add expense` відкриває діалог модально (`exec()`), а введена витрата додається до списку.

**Очікуваний результат:** `exec()` повертає `Accepted` або `Rejected`; кнопка `Ok` недоступна, доки дані некоректні.

### Завдання 5. Помилки файлу

Відкрийте файл з пошкодженими рядками і файл без прав на читання. Покажіть `QMessageBox.warning` з кількістю пропущених рядків і `QMessageBox.critical` для неможливості прочитати файл.

**Очікуваний результат:** застосунок не падає за жодного вмісту файлу, а користувач розуміє, що сталося.
