### Завдання 4. Broadcasting

```python
import numpy as np

week = np.array([[120, 85, 0, 310, 95, 40, 150],
                 [90, 0, 210, 75, 60, 180, 30]])
weekday_limits = np.array([100, 100, 100, 100, 150, 200, 200])
over = week - weekday_limits      # (2, 7) - (7,) -> (2, 7)
print(over)
share = week / week.sum(axis=1, keepdims=True)  # (2, 7) / (2, 1)
print(share.round(2))
```

Застосуйте ці операції до ваших даних: відніміть ваші ліміти по днях тижня і обчисліть частку кожного дня у витратах тижня. Поясніть, навіщо `keepdims=True`.

**Очікуваний результат:** сума часток у кожному рядку дорівнює `1`; без `keepdims=True` ділення генерує помилку несумісних форм — у звіті її текст.
