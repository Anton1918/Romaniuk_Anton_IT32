## Хід роботи

### Завдання 1. Групування

Файл `task1.py`. Для кожної категорії обчисліть кількість, суму, середнє й максимальну витрату одним викликом:

```python
import pandas as pd

df = pd.DataFrame({
    "category": ["food", "food", "transport", "fun", "food"],
    "amount": [85.5, 120.0, 30.0, 315.0, 64.5],
})
report = df.groupby("category")["amount"].agg(["count", "sum", "mean", "max"])
print(report.sort_values("sum", ascending=False))
```

**Очікуваний результат:** суми за категоріями збігаються з результатами 5–6 семестрів, а частки в сумі дають 100 %.
