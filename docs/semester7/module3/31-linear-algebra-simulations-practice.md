### Завдання 2. Система рівнянь

Ви купили зошити, ручки та маркери у трьох магазинах. Відомі кількість кожного товару в кожній покупці та загальна сума покупки (ваші реальні або правдоподібні дані). Знайдіть ціну кожного товару:

```python
import numpy as np

counts = np.array([[3, 2, 1],
                   [1, 4, 2],
                   [2, 1, 3]])
totals = np.array([155.0, 190.0, 185.0])
prices = np.linalg.solve(counts, totals)
print(prices.round(2))
print(np.allclose(counts @ prices, totals))
```

**Очікуваний результат:** ціни додатні, а перевірка підстановкою повертає `True`.
