## Хід роботи

### Завдання 1. Читання і дослідження

Файл `task1.py`:

```python
import pandas as pd

df = pd.read_csv(
    "data/expenses.csv",
    sep=";",
    comment="#",
    names=["date", "category", "amount", "comment"],
    parse_dates=["date"],
)
print(df.head())
df.info()
print(df.describe())
```

**Очікуваний результат:** стовпець `date` має тип `datetime64`, `amount` — `float64`; кількість рядків збігається з кількістю ваших витрат.
