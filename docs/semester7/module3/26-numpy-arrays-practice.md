## Хід роботи

### Завдання 1. Створення масивів

Файл `task1.py`. Створіть і виведіть з атрибутами `shape`, `dtype`, `ndim`:

1. Масив з ваших 5 оцінок за минулий семестр (`np.array`).
2. Матрицю нулів 3×4 і одиниць 2×5.
3. Діапазон від 0 до 1 з 11 точками (`np.linspace`).
4. Матрицю 4×7 випадкових цілих від 0 до 500, створену генератором `np.random.default_rng(seed)`.

```python
import numpy as np

seed = 20070307  # дата вашого народження YYYYMMDD
rng = np.random.default_rng(seed)
week = rng.integers(0, 500, size=(4, 7))
print(week)
print(week.shape, week.dtype, week.ndim)
```

**Очікуваний результат:** при повторних запусках випадкова матриця однакова, бо генератор має фіксоване початкове значення.
