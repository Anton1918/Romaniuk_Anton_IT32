## Хід роботи

### Завдання 1. Клас Money

Файл `task1.py`. Створіть клас `Money(amount, currency)`, де сума зберігається в копійках (`int`), щоб уникнути помилок округлення.

```python
class Money:
    def __init__(self, amount, currency="UAH"):
        self.cents = round(amount * 100)
        self.currency = currency

    def __add__(self, other):
        if self.currency != other.currency:
            raise ValueError("different currencies")
        return Money((self.cents + other.cents) / 100, self.currency)

    def __str__(self):
        return f"{self.cents / 100:.2f} {self.currency}"


print(Money(0.1) + Money(0.2))
```

Додайте `__sub__`, множення на число (`__mul__`), `__repr__` і порівняння `__eq__` та `__lt__`.

**Очікуваний результат:** `Money(0.1) + Money(0.2) == Money(0.3)` повертає `True` (порівняйте з `0.1 + 0.2 == 0.3` для `float`), а додавання гривень і доларів генерує `ValueError`.
