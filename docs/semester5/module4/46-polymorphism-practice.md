## Хід роботи

### Завдання 1. Альтернативні конструктори

Файл `task1.py`. Створіть клас `Expense` (дата, категорія, сума, коментар) і три способи створення обʼєкта:

```python
class Expense:
    def __init__(self, date, category, amount, comment=""):
        self.date = date
        self.category = category
        self.amount = amount
        self.comment = comment

    @classmethod
    def from_csv_line(cls, line):
        date, category, amount, comment = line.strip().split(";")
        return cls(date, category, float(amount), comment)


expense = Expense.from_csv_line("2026-09-21;food;85.50;lunch")
print(expense.category, expense.amount)
```

Додайте методи класу `from_dict(data)` для запису з JSON і `from_input()`, що запитує дані з клавіатури. Завантажте ваші витрати з обох файлів і порівняйте кількість.

**Очікуваний результат:** обʼєкти, створені з CSV і з JSON, мають однакові дані; конструктор `__init__` не містить логіки розбору рядків.

### Завдання 2. Статичні методи-перевірки

Додайте статичні методи `is_valid_date(text)` (формат `YYYY-MM-DD`, використайте `datetime.strptime`) та `is_valid_amount(value)`. Використайте їх у `from_csv_line` і пропускайте некоректні рядки з повідомленням.

**Очікуваний результат:** статичні методи можна викликати без створення обʼєкта (`Expense.is_valid_date("2026-02-30")` повертає `False`).

### Завдання 3. Змінна класу

Додайте змінну класу `currency = "UAH"` і лічильник створених обʼєктів. Створіть метод класу `set_currency(code)`, що змінює валюту для всіх витрат одночасно.

**Очікуваний результат:** після виклику `Expense.set_currency("USD")` усі обʼєкти виводять суми з новим позначенням валюти.

### Завдання 4. Поліморфізм

Обчисліть ваш баланс за місяць одним циклом по змішаному списку.
