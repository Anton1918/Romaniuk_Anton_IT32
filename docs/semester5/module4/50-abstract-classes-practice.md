## Хід роботи

### Завдання 1. Абстрактний експортер

Файл `exporters.py`. Створіть абстрактний клас `Exporter` з абстрактним методом `export(expenses, path)` і звичайним методом `extension()`:

```python
from abc import ABC, abstractmethod
from pathlib import Path


class Exporter(ABC):
    @abstractmethod
    def export(self, expenses, path):
        """Write expenses to the file at path."""

    def target(self, name):
        return Path(f"{name}.{self.extension()}")

    @abstractmethod
    def extension(self):
        """Return file extension without dot."""


try:
    Exporter()
except TypeError as error:
    print("error:", error)
```

**Очікуваний результат:** спроба створити `Exporter()` генерує `TypeError` з переліком нереалізованих абстрактних методів.
