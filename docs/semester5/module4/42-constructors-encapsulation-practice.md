### Завдання 3. Властивість @property

Замініть прямий доступ до балансу властивістю:

```python
class Wallet:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance  # викликає сетер

    @property
    def balance(self):
        return self.__balance

    @balance.setter
    def balance(self, value):
        if value < 0:
            raise ValueError("balance can not be negative")
        self.__balance = round(value, 2)


wallet = Wallet("Ivan Petrenko", 1500)
print(wallet.balance)
wallet.balance = 1200.555
print(wallet.balance)
```

Додайте властивість `owner` з перевіркою на порожній рядок і властивість лише для читання `is_empty`.

**Очікуваний результат:** присвоєння від’ємного балансу генерує `ValueError`, а спроба присвоїти `is_empty` — `AttributeError`.
