## Хід роботи

### Завдання 1. Віртуальне середовище

1. Створіть і активуйте віртуальне середовище:

    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

2. Переконайтеся, що активне саме воно: команди `which python` і `python -c "import sys; print(sys.prefix)"` мають показувати шлях до `lab32/.venv`.
3. Виконайте `pip list` і запишіть, які пакети є в новому середовищі.
4. Деактивуйте середовище (`deactivate`) і повторіть `which python`.

**Очікуваний результат:** у звіті два виводи `which python` — до і після `deactivate` — і перелік пакетів «чистого» середовища (лише `pip`).

### Завдання 2. Звіт про витрати з бібліотекою tabulate

Файл `task2.py`. Встановіть пакет `tabulate` (`pip install tabulate`) і виведіть ваші витрати таблицею.

1. Прочитайте `data/expenses.csv`, пропускаючи коментарі та порожні рядки (як у роботі 22).
2. Згрупуйте суми за категоріями та виведіть таблицю `category | count | total` функцією `tabulate` у форматі `github`.
3. Останнім рядком таблиці виведіть загальну суму.

```text
$ python3 task2.py
Ivan Petrenko, PZ-11
| category   |   count |   total |
|------------|---------|---------|
| food       |       9 |  642.50 |
| transport  |       6 |  210.00 |
| fun        |       2 |  395.50 |
| TOTAL      |      17 | 1248.00 |
```

**Очікуваний результат:** таблиця містить усі ваші категорії, суми збігаються з результатом роботи 22, а програма без активного `.venv` завершується помилкою `ModuleNotFoundError`. Покажіть обидва запуски.

### Завдання 3. QR-код з вашими контактами

Файл `task3.py`. Встановіть `qrcode[pil]` і згенеруйте файл `contact.png` з QR-кодом, що містить рядок `Ivan Petrenko, PZ-11, ivan.petrenko@example.com` (ваші дані).

```python
import qrcode

# дані студента — латиницею
text = "Ivan Petrenko, PZ-11, ivan.petrenko@example.com"
image = qrcode.make(text)
image.save("contact.png")
print("saved: contact.png")
```

Відскануйте код телефоном і перевірте, що він містить саме ваші дані.

**Очікуваний результат:** файл `contact.png` відкривається, а після сканування показує ваш рядок без помилок.

### Завдання 4. Фіксація та відтворення залежностей

1. Збережіть залежності: `pip freeze > requirements.txt`. Поясніть, чому в ньому більше пакетів, ніж ви встановлювали вручну.
2. Створіть поруч каталог `lab32_copy`, скопіюйте туди `task2.py`, `data/` і `requirements.txt`.
3. У `lab32_copy` створіть нове середовище, встановіть залежності командою `pip install -r requirements.txt` і запустіть `task2.py`.
4. Виконайте `pip show tabulate`: запишіть версію, ліцензію та розташування пакета.

**Очікуваний результат:** `task2.py` у новому каталозі працює без жодного ручного `pip install`, а версії пакетів у двох середовищах однакові (порівняйте `pip freeze`).

### Завдання 5. Оновлення та видалення пакета

1. Встановіть стару версію: `pip install "tabulate==0.8.10"` і перевірте версію в програмі (`tabulate.__version__`).
2. Оновіть пакет: `pip install --upgrade tabulate`.
3. Видаліть `qrcode` і переконайтеся, що `task3.py` більше не запускається.

**Очікуваний результат:** у звіті три виводи версії або помилки імпорту, що підтверджують кожну дію.
