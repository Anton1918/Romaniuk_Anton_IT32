## Хід роботи

### Завдання 1. Перший запит

Файл `task1.py`. Отримайте курси валют НБУ, виведіть код стану, заголовок `Content-Type` і кількість валют у відповіді. Знайдіть у відповіді курси долара (`USD`) і євро (`EUR`).

```python
import requests

URL = "https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange"

response = requests.get(URL, params={"json": ""}, timeout=10)
response.raise_for_status()
rates = response.json()
print("status:", response.status_code)
print("currencies:", len(rates))
```

**Очікуваний результат:** програма виводить код `200`, кількість валют і два курси з датою, на яку їх встановлено (поле `exchangedate`).

### Завдання 4. Обробка помилок

Додайте до `task2.py` обробку трьох ситуацій і покажіть кожну у звіті:

1. Немає інтернету (вимкніть Wi-Fi) — `requests.ConnectionError`.
2. Неіснуюча адреса (змініть шлях у `URL`) — код `404`, `requests.HTTPError`.
3. Таймаут — встановіть `timeout=0.001` і перехопіть `requests.Timeout`.

**Очікуваний результат:** у жодному з випадків програма не завершується трасуванням винятку: виводиться зрозуміле повідомлення в `sys.stderr`, а код завершення дорівнює `1`.

### Завдання 5. Кеш відповіді

Файл `task5.py`. Щоб не звертатися до API щоразу, збережіть відповідь НБУ у `cache/rates.json` разом з часом отримання. Якщо кешу менше години — використовуйте його, інакше — виконайте новий запит. Виведіть, звідки взято дані.

```text

$ python3 task5.py

source: cache (age 12 s)
```

**Очікуваний результат:** другий запуск протягом години не виконує мережевого запиту, а після видалення кешу дані знову беруться з API.
