# 36. (П16) Серіалізація даних: робота з JSON

## Мета роботи

- **Освітня (навчальна):** навчитися перетворювати дані Python у JSON і назад функціями `json.dump`, `json.dumps`, `json.load`, `json.loads`, зберігати конфігурацію програми у JSON-файлі та обробляти помилки формату.
- **Дослідна (розвиваюча):** розвинути вміння досліджувати, які типи Python підтримує JSON, і самостійно розвʼязувати проблему серіалізації непідтримуваних типів.
- **Виховна (патріотична):** сформувати інтерес до відкритих даних України: JSON — основний формат обміну даними державних реєстрів і порталу data.gov.ua.

!!! danger "Персоналізація обовʼязкова"
    Програми працюють з **вашим** файлом витрат з роботи 22 і вашими особистими налаштуваннями.

## Підготовка

Створіть каталог `lab36` і скопіюйте `data/expenses.csv` з роботи 22. Кожне завдання — в окремому файлі `task1.py` … `task4.py`. Перший рядок виводу кожної програми — ваше імʼя, прізвище і група.

## Хід роботи

### Завдання 1. CSV → JSON

Файл `task1.py`. Перетворіть ваш `data/expenses.csv` на `data/expenses.json`: список обʼєктів з полями `date`, `category`, `amount` (число), `comment`.

1. Запишіть файл з параметрами `indent=2` та `ensure_ascii=False`, кодування `utf-8`.
2. Виведіть кількість записаних обʼєктів і розмір файлу в байтах.

```text
$ python3 task1.py
Ivan Petrenko, PZ-11
records: 17
saved: data/expenses.json (2154 bytes)
```

**Очікуваний результат:** файл відкривається у VS Code, містить коректний JSON (перевірте `python3 -m json.tool data/expenses.json`), суми записані числами, а не рядками.

### Завдання 2. Повний цикл: прочитати → змінити → записати

Файл `task2.py`. Програма:

1. Читає `data/expenses.json`.
2. Додає новий запис з сьогоднішньою датою (`date.today().isoformat()`).
3. Видаляє всі записи з сумою менше 10.
4. Записує результат у `data/expenses_updated.json` і виводить, скільки записів додано та видалено.

**Очікуваний результат:** вихідний файл не змінено, новий файл містить ваш доданий запис, а записів з сумою менше 10 у ньому немає.

### Завдання 3. Налаштування програми у settings.json

Файл `task3.py`. Програма зберігає ваші налаштування у `settings.json`:

```json
{
  "owner": "Ivan Petrenko",
  "group": "PZ-11",
  "currency": "UAH",
  "monthly_limit": 6000,
  "categories": ["food", "transport", "fun"]
}
```

1. Якщо файлу немає — створити його зі значеннями за замовчуванням і повідомити про це.
2. Якщо файл є — прочитати, вивести налаштування і порівняти загальну суму ваших витрат з `monthly_limit`.
3. Якщо файл пошкоджено (видаліть у ньому кому), перехопити `json.JSONDecodeError`, вивести номер рядка помилки в `sys.stderr` і завершити програму з кодом `1`.

```text
$ python3 task3.py
Ivan Petrenko, PZ-11
settings.json not found, default created
$ python3 task3.py
Ivan Petrenko, PZ-11
limit: 6000.00 UAH, spent: 1248.00 UAH, left: 4752.00 UAH
```

**Очікуваний результат:** три запуски — без файлу, з коректним і з пошкодженим файлом — дають три різні результати, а пошкоджений файл не перезаписується.

### Завдання 4. Серіалізація дати

Файл `task4.py`. Спробуйте серіалізувати словник, у якому є обʼєкт `date`, і зафіксуйте текст помилки `TypeError`. Потім розвʼяжіть проблему двома способами:

1. Параметром `default=` з функцією, що перетворює `date` на рядок ISO.
2. Власною функцією, яка перед записом перетворює всі дати на рядки, а після читання — назад на `date`.

**Очікуваний результат:** після запису й читання дані збігаються з вихідними (`==` повертає `True`), а дати після читання знову є обʼєктами `date`.
