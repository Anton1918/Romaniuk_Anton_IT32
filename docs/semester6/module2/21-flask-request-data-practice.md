# 21. (П10) Передача даних в HTTP-запиті

## Мета роботи

- **Освітня (навчальна):** навчитися отримувати дані з рядка запиту (`request.args`), форми (`request.form`) і JSON-тіла (`request.get_json()`), перевіряти їх і повертати зрозумілі помилки з кодом `400`.
- **Дослідна (розвиваюча):** розвинути вміння передбачати некоректні дані від клієнта і перевіряти поведінку сервера на граничних випадках.
- **Виховна (патріотична):** сформувати відповідальність за безпеку сервісу: сервер ніколи не довіряє даним, що надходять ззовні.

    Продовжуйте **ваш** проєкт з роботи П9; тестові запити містять ваші реальні задачі та дисципліни.

## Підготовка

Скопіюйте `lab09_flask` у `lab10_request_data`. Для запитів використовуйте `curl`: параметр `-i` показує код стану й заголовки, `-X` задає метод, `-H` — заголовок, `-d` — тіло запиту.

## Хід роботи

### Завдання 1. Параметри рядка запиту

Розширте `GET /tasks` фільтрами `?status=todo`, `?subject=Programming` і `?limit=3`. Невідомий статус — код `400` з переліком допустимих значень.

```bash
curl "http://127.0.0.1:5000/tasks?status=todo&limit=2"
```

**Очікуваний результат:** фільтри можна поєднувати; `limit=abc` або `limit=-1` повертає `400`, а не помилку сервера `500`.

### Завдання 2. JSON-тіло запиту

Реалізуйте `POST /tasks`, що приймає JSON і перевіряє поля:

```python
from flask import Flask, jsonify, request

app = Flask(__name__)
TASKS = []
STATUSES = {"todo", "in_progress", "done"}


@app.post("/tasks")
def create_task():
    data = request.get_json(silent=True)
    if not isinstance(data, dict):
        return jsonify({"error": "JSON object expected"}), 400
    title = data.get("title")
    if not isinstance(title, str) or not title.strip():
        return jsonify({"error": "title is required", "field": "title"}), 400
    status = data.get("status", "todo")
    if status not in STATUSES:
        return jsonify({"error": "unknown status", "field": "status"}), 400
    task = {"id": len(TASKS) + 1, "title": title.strip(), "status": status}
    TASKS.append(task)
    return jsonify(task), 201


if __name__ == "__main__":
    app.run(debug=True)
```

Додайте перевірку поля `due_date` (формат `YYYY-MM-DD`, дата не в минулому) і `subject`.

**Очікуваний результат:** коректний запит повертає `201` і створену задачу; кожне некоректне поле дає `400` з назвою поля у відповіді.

### Завдання 3. Дані форми

Додайте маршрут `POST /tasks/form`, що приймає ті самі поля з HTML-форми (`request.form`). Створіть файл `form.html` з формою і надішліть її з браузера.

**Очікуваний результат:** задача, створена через форму, зʼявляється у `GET /tasks`; у звіті пояснено, чим відрізняються заголовки `Content-Type` двох способів.

### Завдання 4. Складний JSON

Реалізуйте `POST /tasks/batch`, що приймає список задач з вкладеним списком підзадач:

```json
{
  "tasks": [
    {"title": "Course project", "subject": "Programming", "subtasks": ["design", "code", "report"]}
  ]
}
```

Якщо хоча б одна задача некоректна — не створюйте жодної і поверніть перелік помилок з індексами.

**Очікуваний результат:** запит з однією некоректною задачею не змінює список задач і повертає `400` з усіма помилками.
