## Мета роботи

- **Виховна (патріотична):** сформувати відповідальне ставлення до навантаження на публічні державні сервіси (API Національного банку України) і культуру «ввічливого» клієнта.

## Хід роботи

### Завдання 1. Послідовне завантаження

Файл `task1.py`. Напишіть функцію `get_rate(day)`, що повертає курс USD на дату `day` (обʼєкт `date`). Завантажте курси за всі дні вашого місяця послідовно, виведіть кожен курс і загальний час.

```python
from datetime import date

import requests

URL = "https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange"


def get_rate(day):
    params = {"valcode": "USD", "date": day.strftime("%Y%m%d"), "json": ""}
    response = requests.get(URL, params=params, timeout=10)
    response.raise_for_status()
    return response.json()[0]["rate"]


print(get_rate(date(2025, 10, 7)))
```

**Очікуваний результат:** програма виводить курс за кожен день місяця і час, витрачений на всі запити.
