# 41. (П20) Налагодження асинхронного коду та робота з подієвим циклом

## Мета роботи

- **Освітня (навчальна):** навчитися вмикати режим налагодження asyncio, знаходити корутини без `await`, повільні та блокуючі виклики, незавершені задачі й виносити блокуючий код у потік (`asyncio.to_thread`, `loop.run_in_executor`).
- **Дослідна (розвиваюча):** розвинути вміння читати попередження інтерпретатора й локалізувати причину уповільнення асинхронної програми.
- **Виховна (патріотична):** сформувати наполегливість у з’ясуванні причин помилок, без якої неможлива підтримка надійних систем.

!!! danger "Персоналізація обовʼязкова"
    Налагоджується **ваш** код з робіт П18–П19; час «повільного» виклику дорівнює дню вашого народження в десятих частках секунди (для 7-го числа — 0.7 с).

## Хід роботи

### Завдання 1. Режим налагодження

Файл `task1.py`. Запустіть програму з помилками в режимі налагодження двома способами: `asyncio.run(main(), debug=True)` і змінною середовища `PYTHONASYNCIODEBUG=1`.

```python
import asyncio
import time


async def save_report():
    await asyncio.sleep(0.1)


async def slow_step():
    time.sleep(0.7)  # блокуючий виклик: ваш день народження / 10


async def main():
    save_report()  # помилка: немає await
    await slow_step()


asyncio.run(main(), debug=True)
```

**Очікуваний результат:** у виводі два попередження: `coroutine 'save_report' was never awaited` і `Executing <Task ...> took 0.700 seconds`; у звіті пояснено кожне.

### Завдання 2. Блокуючі виклики

Файл `task2.py`. Три задачі викликають блокуючу функцію (`time.sleep` або `requests.get`). Виміряйте час, потім виправте програму двома способами:

1. `await asyncio.to_thread(blocking_function, ...)`.
2. `await loop.run_in_executor(None, blocking_function, ...)`.

**Очікуваний результат:** до виправлення задачі виконуються послідовно, після — конкурентно; у звіті таблиця часу трьох варіантів.

### Завдання 3. Незавершені задачі

Файл `task3.py`. Створіть кілька задач і завершіть `main()`, не дочекавшись їх. Виведіть перелік незавершених задач через `asyncio.all_tasks()` і назви задач (`create_task(..., name=...)`). Виправте програму так, щоб усі задачі завершувалися коректно.

**Очікуваний результат:** у виправленій версії немає повідомлень `Task was destroyed but it is pending`.

### Завдання 4. Ручне керування подієвим циклом

Файл `task4.py`. Створіть цикл вручну (`asyncio.new_event_loop()`), заплануйте звичайну функцію через `loop.call_later`, запустіть корутину через `loop.run_until_complete` і коректно закрийте цикл. Порівняйте з `asyncio.run`.

**Очікуваний результат:** у звіті пояснено, які дії `asyncio.run` виконує автоматично.
