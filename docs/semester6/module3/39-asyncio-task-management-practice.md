## Хід роботи

### Завдання 1. Асинхронне завантаження з gather

Файл `task1.py`:

```python
import asyncio
from datetime import date, timedelta

import aiohttp

URL = "https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange"


async def get_rate(session, day):
    params = {"valcode": "USD", "date": day.strftime("%Y%m%d"), "json": ""}
    async with session.get(URL, params=params) as response:
        response.raise_for_status()
        data = await response.json(content_type=None)
        return day, data[0]["rate"]


async def main():
    first = date(2025, 10, 1)  # перший день місяця вашого народження
    days = []
    day = first
    while day.month == first.month:
        days.append(day)
        day += timedelta(days=1)
    timeout = aiohttp.ClientTimeout(total=10)
    async with aiohttp.ClientSession(timeout=timeout) as session:
        results = await asyncio.gather(*(get_rate(session, day) for day in days))
    for day, rate in results:
        print(day, rate)


asyncio.run(main())
```

Замініть дату на ваш місяць і виміряйте час.

**Очікуваний результат:** курси збігаються з `rates.csv` з роботи П17, а час близький до варіанта з 10 потоками.
