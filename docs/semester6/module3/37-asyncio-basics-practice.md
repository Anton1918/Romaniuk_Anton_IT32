## Мета роботи

- **Освітня (навчальна):** навчитися створювати корутини (`async def`), чекати на них (`await`), запускати їх конкурентно як задачі (`asyncio.create_task`) і запускати подієвий цикл (`asyncio.run`).
- **Дослідна (розвиваюча):** розвинути вміння передбачати порядок виконання асинхронного коду та перевіряти свої передбачення експериментально.

## Хід роботи

### Завдання 1. Послідовні корутини

Файл `task1.py`. Опишіть 4 ваші ранкові справи корутинами з `asyncio.sleep` (наприклад, закип’ятити чайник — 3 с, зробити бутерброд — 2 с, зібрати рюкзак — 2 с, перевірити розклад — 1 с) і виконайте їх послідовно через `await`.

```python
import asyncio
import time


async def chore(name, seconds):
    print(f"start {name}")
    await asyncio.sleep(seconds)
    print(f"done  {name}")
    return name


async def main():
    start = time.perf_counter()
    await chore("boil kettle", 3)
    await chore("make sandwich", 2)
    print(f"total: {time.perf_counter() - start:.1f} s")


asyncio.run(main())
```

**Очікуваний результат:** загальний час дорівнює сумі тривалостей усіх справ.

### Завдання 2. Конкурентні задачі

Файл `task2.py`. Запустіть ті самі справи як задачі (`asyncio.create_task`) і дочекайтеся їх. Поясніть порядок рядків `start`/`done` у виводі.

**Очікуваний результат:** загальний час дорівнює тривалості найдовшої справи, а всі `start` виводяться до першого `done`.

### Завдання 3. Залежні справи

Деякі справи залежать одна від одної: чай можна заварити лише після того, як закипить чайник. Організуйте виконання так, щоб незалежні справи йшли конкурентно, а залежні — по черзі. Намалюйте схему залежностей (mermaid або від руки).

**Очікуваний результат:** загальний час дорівнює найдовшому ланцюжку залежних справ; у звіті схема і розрахунок очікуваного часу.

### Завдання 4. Типові помилки

Покажіть і поясніть три помилки:

1. Виклик корутини без `await` — попередження `coroutine ... was never awaited`.
2. `time.sleep(2)` замість `await asyncio.sleep(2)` у корутині — конкурентність зникає.
3. Виклик `asyncio.run()` всередині корутини — `RuntimeError`.

**Очікуваний результат:** для кожної помилки у звіті вивід програми і виправлений варіант.
