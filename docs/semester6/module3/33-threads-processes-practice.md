## Хід роботи

### Завдання 1. Задача з очікуванням

Файл `task1.py`. Функція `download(name)` імітує завантаження файлу: `time.sleep(1)`. Виконайте 8 «завантажень» трьома способами і виміряйте час:

1. Послідовно.
2. У 8 потоках (`threading.Thread`, `start()`, `join()`).
3. У пулі потоків `ThreadPoolExecutor(max_workers=4)`.

```python
import threading
import time


def download(name):
    time.sleep(1)  # імітація очікування мережі
    print("done", name)


start = time.perf_counter()
threads = [threading.Thread(target=download, args=(f"file{i}",)) for i in range(8)]
for thread in threads:
    thread.start()
for thread in threads:
    thread.join()
print(f"threads: {time.perf_counter() - start:.2f} s")
```

**Очікуваний результат:** послідовно — близько 8 с, у 8 потоках — близько 1 с, у пулі з 4 потоків — близько 2 с.
