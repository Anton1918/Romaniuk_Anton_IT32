## Хід роботи

### Завдання 1. Неблокуючий accept

Переведіть серверний сокет у неблокуючий режим (`server.setblocking(False)`) і викличте `accept()` без підключених клієнтів. Перехопіть `BlockingIOError` і поясніть, що він означає.

**Очікуваний результат:** `accept()` не чекає, а одразу генерує `BlockingIOError`; у звіті текст винятку і пояснення.

### Завдання 2. Сервер з опитуванням

Файл `server.py`. Сервер у нескінченному циклі:

1. Намагається прийняти нового клієнта й додає його сокет (також неблокуючий) до списку.
2. Для кожного клієнта намагається прочитати дані й надіслати їх назад.
3. Видаляє зі списку клієнтів, що відключилися.

```python
import socket

PORT = 9007
clients = []

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server.bind(("127.0.0.1", PORT))
server.listen()
server.setblocking(False)

while True:
    try:
        conn, address = server.accept()
        conn.setblocking(False)
        conn.sendall(b"hello from Ivan Petrenko (PZ-11)\n")
        clients.append(conn)
        print("connected", address)
    except BlockingIOError:
        pass
    for conn in clients[:]:
        try:
            data = conn.recv(1024)
        except BlockingIOError:
            continue
        if data:
            conn.sendall(data)
        else:
            clients.remove(conn)
            conn.close()
            print("disconnected")
```

**Очікуваний результат:** три клієнти одночасно отримують відповіді на свої повідомлення, не чекаючи один одного.

### Завдання 3. Ціна опитування

Поки сервер працює без клієнтів, подивіться завантаження процесора процесом сервера (`top` або `htop`). Додайте `time.sleep(0.01)` наприкінці циклу і повторіть вимірювання.

**Очікуваний результат:** без паузи процес займає близько 100 % одного ядра, з паузою — майже 0 %; у звіті пояснено, чому пауза не є повноцінним розвʼязанням (затримка відповіді).

### Завдання 4. Буфер на відправлення

Великі відповіді можуть не відправитися повністю за один `send`. Замініть `sendall` на `send`, зберігайте невідправлений залишок для кожного клієнта у словнику і дописуйте його на наступних ітераціях. Перевірте, надіславши рядок довжиною 1 МБ (`python3 -c "print('x' * 1_000_000)" | nc localhost 9007`).

**Очікуваний результат:** клієнт отримує всі байти (порівняйте розмір надісланого й отриманого), а сервер не блокується.
