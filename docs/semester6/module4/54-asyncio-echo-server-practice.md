## Хід роботи

### Завдання 1. Асинхронний ехо-сервер

Файл `server.py`:

```python
import asyncio

PORT = 9007  # 9000 + ваш номер у списку


async def handle(reader, writer):
    address = writer.get_extra_info("peername")
    writer.write(b"hello from Ivan Petrenko (PZ-11)\n")
    await writer.drain()
    while line := await reader.readline():
        writer.write(line)
        await writer.drain()
    print("disconnected", address)
    writer.close()
    await writer.wait_closed()


async def main():
    server = await asyncio.start_server(handle, "127.0.0.1", PORT)
    print(f"listening on {PORT}")
    async with server:
        await server.serve_forever()


asyncio.run(main())
```

Підключіть одночасно три клієнти `nc`.

**Очікуваний результат:** усі клієнти обслуговуються одночасно, а код не містить жодного явного циклу опитування сокетів.

### Завдання 2. Команди та журнал

Перенесіть протокол команд з роботи П21 (`TIME`, `UPPER`, `QUIT`) в асинхронний сервер і додайте команду `USERS` — кількість підключених клієнтів. Кожне повідомлення записуйте в `log_<прізвище>.txt` з часом і адресою клієнта.

**Очікуваний результат:** команди працюють для кожного клієнта незалежно, а журнал містить повідомлення всіх клієнтів у порядку надходження.

### Завдання 3. Навантажувальний тест

Файл `load_client.py`. Клієнт на asyncio відкриває 100 з’єднань одночасно (`asyncio.open_connection`), кожне надсилає 10 повідомлень і перевіряє відповіді. Виміряйте загальний час. Запустіть той самий тест проти блокуючого сервера з роботи П21.

**Очікуваний результат:** асинхронний сервер обслуговує всі 100 клієнтів за частки секунди; блокуючий — обслуговує їх по одному. У звіті таблиця часу.

### Завдання 4. Коректне завершення (graceful shutdown)

Обробіть сигнал зупинки (Ctrl+C) так, щоб сервер:

1. Перестав приймати нові з’єднання (`server.close()`).
2. Надіслав усім підключеним клієнтам `server is shutting down` і закрив їхні з’єднання.
3. Дочекався завершення всіх обробників і записав у журнал рядок `shutdown`.

**Очікуваний результат:** після Ctrl+C клієнти отримують повідомлення про зупинку, сервер завершується без трасування винятків, а остання строка журналу — `shutdown`.
