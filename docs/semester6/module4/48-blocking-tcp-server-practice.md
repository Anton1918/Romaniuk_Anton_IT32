# 48. (П21) Блокуючий ехо-сервер (TCP) на модулі socket

## Мета роботи

- **Освітня (навчальна):** навчитися створювати TCP-сервер і клієнта модулем `socket`: виконувати `bind`, `listen`, `accept`, `recv`, `sendall`, коректно закривати з’єднання та обробляти відключення клієнта.
- **Дослідна (розвиваюча):** розвинути вміння досліджувати мережеву взаємодію інструментами (`nc`, `ss`/`netstat`) і експериментально виявляти обмеження блокуючого режиму.
- **Виховна (патріотична):** сформувати культуру безпечної мережевої взаємодії та розуміння ролі надійних мереж для стійкості критичної інфраструктури України.

!!! danger "Персоналізація обовʼязкова"
    Сервер слухає порт `9000 + N`, де `N` — ваш номер у списку групи, і вітає клієнта рядком з вашим імʼям: `hello from Ivan Petrenko (PZ-11)`.

## Підготовка

Створіть каталог `lab21_tcp`. Знадобляться два термінали: в одному працює сервер, в іншому — клієнт. Для перевірки зручно використовувати `nc localhost 9007` (netcat).

## Хід роботи

### Завдання 1. Ехо-сервер

Файл `server.py`:

```python
import socket

HOST = "127.0.0.1"
PORT = 9007  # 9000 + ваш номер у списку

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as server:
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind((HOST, PORT))
    server.listen()
    print(f"listening on {HOST}:{PORT}")
    while True:
        conn, address = server.accept()
        with conn:
            print("connected", address)
            conn.sendall(b"hello from Ivan Petrenko (PZ-11)\n")
            while data := conn.recv(1024):
                conn.sendall(data)
            print("disconnected", address)
```

Підключіться через `nc` і надішліть кілька рядків.

**Очікуваний результат:** сервер вітає клієнта вашим рядком і повертає кожне повідомлення без змін; після закриття `nc` сервер виводить `disconnected` і чекає наступного клієнта.

### Завдання 2. Клієнт

Файл `client.py`. Клієнт підключається до сервера, читає привітання, надсилає три повідомлення з вашими даними (імʼя, група, улюблена дисципліна) і виводить відповіді.

**Очікуваний результат:** кожна відповідь збігається з надісланим повідомленням; клієнт завершується без помилок.

### Завдання 3. Обмеження блокуючого сервера

1. Підключіть першого клієнта (`nc`) і не закривайте його.
2. Підключіть другого клієнта і надішліть повідомлення.
3. Закрийте першого клієнта.

**Очікуваний результат:** другий клієнт не отримує відповіді, доки не відключиться перший; у звіті пояснено, на якому виклику блокується сервер.

### Завдання 4. Протокол команд

Додайте до сервера команди: `TIME` — поточний час сервера, `UPPER <text>` — текст великими літерами, `QUIT` — сервер закриває з’єднання. Невідома команда — відповідь `error: unknown command`. Повідомлення розділяються символом нового рядка.

**Очікуваний результат:** команди працюють через `nc` і через ваш `client.py`; повідомлення, що прийшли частинами або разом в одному `recv`, обробляються коректно.

### Завдання 5. Стан з’єднань

Поки сервер працює і клієнт підключений, виконайте `ss -tanp | grep 9007` (або `netstat -an`) і знайдіть стани `LISTEN` і `ESTABLISHED`.

**Очікуваний результат:** у звіті вивід команди з поясненням кожного рядка.
