## Хід роботи

### Завдання 1. Створення бази та таблиці

Файл `create_db.py`. Створіть базу `expenses.db` і таблицю:

```python
import sqlite3

conn = sqlite3.connect("expenses.db")
conn.execute(
    """
    CREATE TABLE IF NOT EXISTS expenses (
        id INTEGER PRIMARY KEY,
        spent_on TEXT NOT NULL,
        category TEXT NOT NULL,
        amount REAL NOT NULL CHECK (amount > 0),
        comment TEXT
    )
    """
)
conn.commit()
conn.close()
print("table created")
```

**Очікуваний результат:** у DB Browser видно таблицю `expenses` з п’ятьма стовпцями; повторний запуск програми не генерує помилки завдяки `IF NOT EXISTS`.

### Завдання 2. Імпорт ваших витрат

Файл `import_csv.py`. Прочитайте `data/expenses.csv` і додайте всі записи в таблицю одним викликом `executemany` з параметрами `?`. Виведіть кількість доданих рядків.

**Очікуваний результат:** `SELECT COUNT(*) FROM expenses` повертає стільки ж рядків, скільки записів у файлі; повторний імпорт не дублює дані (очистіть таблицю перед імпортом або перевіряйте наявність).

### Завдання 4. SQL-інʼєкція

Створіть файл `injection.py`, що шукає витрати за коментарем **небезпечним** способом — f-рядком у запиті. Введіть рядок `' OR '1'='1` і покажіть, що програма повертає всі записи. Потім перепишіть запит з параметром `?` і повторіть спробу.

**Очікуваний результат:** небезпечна версія повертає всі рядки таблиці, безпечна — жодного; у звіті пояснено, чому так відбувається.
