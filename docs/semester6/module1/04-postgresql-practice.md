# 4. (П2) Python та PostgreSQL: бібліотека psycopg2

## Мета роботи

- **Освітня (навчальна):** навчитися підключатися до PostgreSQL з Python бібліотекою `psycopg2`, створювати таблиці, виконувати параметризовані запити `INSERT` і `SELECT` та переносити дані з SQLite у PostgreSQL.
- **Дослідна (розвиваюча):** розвинути розуміння клієнт-серверної архітектури та вміння порівнювати поведінку двох СУБД на однакових даних.
- **Виховна (патріотична):** сформувати культуру інформаційної безпеки: облікові дані бази не записуються в код, а зберігаються в змінних середовища.

!!! danger "Персоналізація обовʼязкова"
    Ви переносите у PostgreSQL **вашу** базу витрат з роботи П1. Назва бази — `expenses_<прізвище>` (наприклад, `expenses_petrenko`).

## Підготовка

1. Встановіть PostgreSQL (або скористайтеся контейнером з роботи П7, якщо її вже виконано) і створіть базу `expenses_<прізвище>`.
2. Створіть каталог `lab02_postgres` з віртуальним середовищем і встановіть `psycopg2-binary`.
3. Скопіюйте `expenses.db` з роботи П1.
4. Задайте параметри підключення змінними середовища:

    ```bash
    export PGHOST=localhost
    export PGPORT=5432
    export PGDATABASE=expenses_petrenko
    export PGUSER=postgres
    export PGPASSWORD=your_password
    ```

## Хід роботи

### Завдання 1. Підключення

Файл `connect.py`. Підключіться до бази, використовуючи змінні середовища, і виведіть версію сервера:

```python
import os

import psycopg2

conn = psycopg2.connect(
    host=os.environ["PGHOST"],
    port=os.environ["PGPORT"],
    dbname=os.environ["PGDATABASE"],
    user=os.environ["PGUSER"],
    password=os.environ["PGPASSWORD"],
)
with conn.cursor() as cur:
    cur.execute("SELECT version()")
    print(cur.fetchone()[0])
conn.close()
```

Перевірте, що станеться з неправильним паролем, і перехопіть `psycopg2.OperationalError`.

**Очікуваний результат:** програма виводить версію PostgreSQL; з неправильним паролем — зрозуміле повідомлення без трасування винятку.

### Завдання 2. Таблиця в PostgreSQL

Файл `create_table.py`. Створіть таблицю `expenses` з типами PostgreSQL: `id` — `INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY`, `spent_on` — `DATE`, `amount` — `NUMERIC(10, 2)` з перевіркою `CHECK (amount > 0)`.

**Очікуваний результат:** команда `\d expenses` у `psql` (або вкладка структури в pgAdmin) показує саме ці типи.

### Завдання 3. Перенесення даних з SQLite

Файл `migrate.py`. Прочитайте всі записи з `expenses.db` (SQLite) і додайте їх у PostgreSQL одним викликом `executemany`. Параметри в `psycopg2` позначаються `%s`, а не `?`.

**Очікуваний результат:** кількість рядків і загальна сума в обох базах однакові — програма виводить обидва значення для порівняння.

### Завдання 4. Вибірка з типами PostgreSQL

Файл `report.py`. Виведіть витрати за вказаний діапазон дат (дати — аргументи командного рядка) і поясніть, якого типу значення повертає `psycopg2` для стовпців `DATE` і `NUMERIC` (подивіться `type()`).

**Очікуваний результат:** дати повертаються як `datetime.date`, суми — як `decimal.Decimal`; у звіті пояснено, чому для грошей обрано `NUMERIC`, а не `REAL`.
