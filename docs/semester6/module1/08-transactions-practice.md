# 8. (П4) Обробка помилок і транзакцій при роботі з PostgreSQL

## Мета роботи

- **Освітня (навчальна):** навчитися керувати транзакціями в `psycopg2` (`commit`, `rollback`, контекстний менеджер `with conn`, `SAVEPOINT`) та обробляти помилки бази даних (`psycopg2.Error` і її нащадки).
- **Дослідна (розвиваюча):** розвинути вміння моделювати збої посеред операції та перевіряти, у якому стані залишилися дані.
- **Виховна (патріотична):** сформувати відповідальність за надійність фінансових систем, від яких залежать громадяни: переказ не може «загубити» гроші посередині.

!!! danger "Персоналізація обовʼязкова"
    Рахунки створюються для **ваших** реальних карток або гаманців (готівка, картка, ощадний рахунок) з вашими приблизними залишками.

## Підготовка

Скористайтеся базою з робіт П2–П3. Створіть каталог `lab04_transactions` і таблицю:

```sql
CREATE TABLE accounts (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL UNIQUE,
    balance NUMERIC(10, 2) NOT NULL CHECK (balance >= 0)
);
```

Додайте 3 ваші рахунки з реальними залишками.

## Хід роботи

### Завдання 1. Неатомарний переказ

Файл `transfer_bad.py`. Реалізуйте переказ двома окремими командами `UPDATE` з `commit()` після кожної. Між командами навмисно згенеруйте виняток (наприклад, `raise RuntimeError("power off")`).

**Очікуваний результат:** гроші списано з одного рахунку, але не зараховано на інший; загальна сума на рахунках зменшилася — покажіть баланси до і після.

### Завдання 2. Атомарний переказ

Файл `transfer.py`. Реалізуйте функцію `transfer(conn, source, target, amount)`, що виконує обидві команди в одній транзакції:

```python
def transfer(conn, source, target, amount):
    with conn:  # commit або rollback автоматично
        with conn.cursor() as cur:
            cur.execute(
                "UPDATE accounts SET balance = balance - %s WHERE name = %s",
                (amount, source),
            )
            cur.execute(
                "UPDATE accounts SET balance = balance + %s WHERE name = %s",
                (amount, target),
            )
```

Повторіть сценарій із завданням 1: виняток між командами.

**Очікуваний результат:** після збою баланси обох рахунків не змінилися, а загальна сума залишилася тією самою.

### Завдання 3. Помилки бази даних

Перевірте три ситуації та обробіть кожну окремим `except`:

1. Переказ більшої суми, ніж є на рахунку, — порушення `CHECK` (`psycopg2.errors.CheckViolation`).
2. Додавання рахунку з наявною назвою — `psycopg2.errors.UniqueViolation`.
3. Запит до неіснуючої таблиці — `psycopg2.errors.UndefinedTable`.

Після кожної помилки переконайтеся, що підключення можна використовувати далі.

**Очікуваний результат:** програма виводить зрозуміле повідомлення для кожної помилки, а дані залишаються незмінними.

### Завдання 4. SAVEPOINT

Файл `savepoint.py`. В одній транзакції виконайте три перекази, другий з яких свідомо некоректний. За допомогою `SAVEPOINT` і `ROLLBACK TO SAVEPOINT` скасуйте лише другий переказ і зафіксуйте перший і третій.

**Очікуваний результат:** після виконання змінено баланси лише для першого й третього переказів.
