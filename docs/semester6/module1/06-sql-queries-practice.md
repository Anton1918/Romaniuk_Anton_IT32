# 6. (П3) Розширені SQL-запити з Python: JOIN, агрегатні функції, підзапити

## Мета роботи

- **Освітня (навчальна):** навчитися виконувати з Python запити з об’єднанням таблиць (`JOIN`), групуванням (`GROUP BY`, `HAVING`), агрегатними функціями та підзапитами і виводити результат з назвами стовпців.
- **Дослідна (розвиваюча):** розвинути вміння формулювати запитання до власних даних мовою SQL і перевіряти результат на невеликій вибірці вручну.
- **Виховна (патріотична):** сформувати сумлінність у підготовці звітних даних, на основі яких люди ухвалюють рішення.

!!! danger "Персоналізація обовʼязкова"
    Запити виконуються до **вашої** бази `expenses_<прізвище>` з роботи П2.

## Підготовка

Скористайтеся базою та середовищем з роботи П2. Створіть каталог `lab03_queries`. Допоміжну функцію для виведення результатів запиту винесіть в окремий модуль `db.py`.

## Хід роботи

### Завдання 1. Довідник категорій

Файл `categories.py`. Створіть таблицю `categories(id, name, monthly_limit)` і заповніть її вашими категоріями з реальними місячними лімітами. Додайте до `expenses` стовпець `category_id` із зовнішнім ключем і заповніть його за назвою категорії.

**Очікуваний результат:** кожна витрата посилається на категорію, а запит `SELECT COUNT(*) FROM expenses WHERE category_id IS NULL` повертає `0`.

### Завдання 2. JOIN і групування

Файл `report_join.py`. Виведіть для кожної категорії кількість витрат, суму та ліміт, включно з категоріями без витрат (`LEFT JOIN`). Назви стовпців візьміть з `cursor.description`.

```text
$ python3 report_join.py
Ivan Petrenko, PZ-11
category    count    total    limit
food            9   642.50  3000.00
transport       6   210.00   600.00
fun             2   395.50   500.00
books           0     0.00   300.00
```

**Очікуваний результат:** категорія без витрат присутня з нулями (`COALESCE`), а суми збігаються з роботою П2.

### Завдання 3. Перевищення ліміту

Файл `over_limit.py`. Виведіть категорії, де витрати перевищують 50 % місячного ліміту, за допомогою `HAVING`.

**Очікуваний результат:** у результаті лише категорії, що задовольняють умову; у звіті вказано, чому умову записано в `HAVING`, а не у `WHERE`.

### Завдання 4. Підзапити

Файл `subqueries.py`. Напишіть три запити:

1. Витрати, більші за середню витрату (підзапит у `WHERE`).
2. Середня сума витрати за днями (підзапит у `FROM`: спочатку сума за кожен день, потім середнє).
3. Для кожної витрати — її частка від загальної суми у відсотках (підзапит у `SELECT`).

**Очікуваний результат:** результат кожного запиту перевірено вручну щонайменше на одному рядку, а розрахунок частки в сумі дає 100 %.
