# Програмування Python - 1 семестр

Ласкаво прошу на курс "Програмування Python - 1 семестр"

## Про курс

Курс присвячений основам програмування на Python.
Для кращого засвоєння матеріалу наполегливо рекомендую тестувати та досліджувати код (представлений на лекційних матеріалах) локально.

## Передумови

Спеціальних передумов немає — курс починається з основ.

## Структура курсу

### 5 семестр

#### [Модуль 1: Основи програмування на Python](semester5/module1/01-intro-lecture.md)

Алгоритми та блок-схеми, змінні й типи даних, розгалуження, цикли, функції, основи Git та GitHub.

#### [Модуль 2: Структури даних, робота з файлами та обробка винятків](semester5/module2/14-lists-tuples-lecture.md)

Списки, кортежі, словники та множини, робота з рядками, типізація, файловий ввід/вивід, обробка винятків.

#### [Модуль 3: Розширені можливості Python та робота з бібліотеками](semester5/module3/26-logging-lecture.md)

Логування, модулі та пакети, створення власних модулів, стандартна бібліотека (math, random, datetime, os, sys), зовнішні бібліотеки, тестування, JSON та HTTP-запити.

#### [Модуль 4: Основи об’єктно-орієнтованого програмування](semester5/module4/40-classes-objects-practice.md)

Класи й обʼєкти, конструктори та інкапсуляція, наслідування, поліморфізм, перевантаження операторів, абстрактні класи.

### 6 семестр

#### [Модуль 1: Робота з базами даних за допомогою Python. Основи контейнеризації](semester6/module1/02-sqlite-practice.md)

SQLite і PostgreSQL з Python, розширені SQL-запити, транзакції, тестування коду з базою даних, Docker.

#### [Модуль 2: Проєктування та реалізація REST API на Flask](semester6/module2/17-rest-design-practice.md)

Проєктування REST API, маршрути й дані запиту, CRUD з базою даних, сесії, тестування API, GitHub Actions, розгортання в Docker.

#### [Модуль 3: Основи асинхронного програмування з asyncio](semester6/module3/33-threads-processes-practice.md)

Процеси та потоки, багатопоточне завантаження даних, корутини й задачі asyncio, налагодження асинхронного коду.

#### [Модуль 4: Високопродуктивні асинхронні системи](semester6/module4/48-blocking-tcp-server-practice.md)

Сокети TCP і UDP, блокуючі та неблокуючі ехо-сервери, модуль selectors, ехо-сервер на подієвому циклі asyncio.

### 7 семестр

#### [Модуль 1: Основи PySide6](semester7/module1/02-first-pyside6-app-practice.md)

Віджети, форми, менеджери компоновки, головне вікно, меню й панелі інструментів, діалоги, сигнали та слоти.

#### [Модуль 2: Архітектура застосунків PySide6](semester7/module2/15-project-structure-practice.md)

Структура проєкту, багатовіконні застосунки, Model/View, фонові задачі, налаштування та обробка помилок.

#### [Модуль 3: Числові обчислення та обробка даних (NumPy, pandas)](semester7/module3/26-numpy-arrays-practice.md)

Масиви NumPy, індексація й broadcasting, лінійна алгебра та симуляції, pandas: фільтрація, групування, зведені таблиці.

#### [Модуль 4: Візуалізація даних (matplotlib)](semester7/module4/36-basic-plots-practice.md)

Лінійні графіки, гістограми й діаграми розсіювання, стовпчикові діаграми, інформативні графіки, дашборди.

Матеріали курсу в процесі наповнення.
